# Glossary

One term per concept, used in the code, the API, the database and the conversation.

| English (code) | Spanish (business) | Meaning |
| --- | --- | --- |
| Booking | reserva | A room reserved for a time range by one person |
| Room | sala | A meeting room that can be booked |
| Cancel | cancelar | Withdraw a booking before it starts. The booking is kept with the status Cancelled |
